# 데이터 첫 점검

목적: 구현 전에 데이터의 모양과 함정을 안다. 숫자는 추측하지 않고 실행 결과로만 말한다.

1. 파일 목록과 크기를 본다: `ls -la` · `wc -l`.
2. 표 파일마다 `python3 .harness/tools/profile.py <파일>` 을 돌린다. 출력을 그대로 보여 준다.
3. 출력에서 다음을 짚어 사람에게 질문 목록으로 돌려준다.
   - 결측이 있는 열과 그 비율
   - 형식이 섞인 열(숫자 열에 문자, 날짜 형식이 둘 이상)
   - 단위가 안 보이는 숫자 열
   - 키로 보이는 열의 중복
   - 개인정보 의심 열(`PII?` 표시)
4. 파일이 여럿이면 어떤 열로 이어지는지, 이을 때 빠지는 행이 몇 개인지 센다.
5. 결과를 `NOTES.md` 에 세 줄 이내로 요약한다. 개인정보 값은 적지 않는다.

하지 말 것: 이 단계에서 정제·변환 코드를 쓰지 않는다. 규칙은 담당자 답을 듣고 정한다.
